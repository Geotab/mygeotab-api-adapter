## Upgrading to v5.0.0.3

> **WARNING!** The upgrade instructions provided in this document only apply to Geotab DIG Adapter version **5.0.0.1**.

Version 5.0.0.3 contains a bug fix to the DIG API re-authentication logic. Previously, if the DIG API rejected the adapter's bearer token with a `401 Unauthorized` or `403 Forbidden` response (for example, when the token reached its expiry), the adapter would retry the same rejected token indefinitely instead of re-authenticating — silently halting all delivery of records to MyGeotab until the adapter was manually restarted. The adapter now re-authenticates automatically in this situation, and additionally refreshes its token proactively ahead of expiry as defense-in-depth.

There are **no database schema or configuration file changes in version 5.0.0.3**. Existing `appsettings.json` and `nlog.config` files do not need to be modified.

**Existing v5.0.0.1 installations are recommended to upgrade** to obtain this fix.

### 1 Download

Download the application following the [Download](../../README.md#12-download) instructions in the README.

### 2 Stop Application

Stop the Geotab DIG Adapter if it is running.

### 3 Backup Configuration Files

Backup the existing `appsettings.json` and `nlog.config` files (to keep track of the existing setting values).

### 4 Deploy Application

Replace the existing v5.0.0.1 application files with the new v5.0.0.3 application files. Restore the existing `appsettings.json` and `nlog.config` files (backed-up in [Step 3](#3-backup-configuration-files)) by copying them over the new ones — they do not need to be modified.

### 5 Start Application

Start the Geotab DIG Adapter application and monitor it and its logs for several minutes to ensure that it is working properly, indicating that the upgrade was successful.
