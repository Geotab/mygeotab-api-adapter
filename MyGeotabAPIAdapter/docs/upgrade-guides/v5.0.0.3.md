## Upgrading to v5.0.0.3

> **WARNING!** The upgrade instructions provided in this document only apply to MyGeotab API Adapter version **5.0.0.1**.

There are **no changes to the MyGeotab API Adapter in version 5.0.0.3**. The version is updated for alignment with the broader MyGeotab API Adapter solution, in which a bug fix was made to a different component (the Geotab DIG Adapter — see its [CHANGELOG](../../../GeotabDIGAdapter/CHANGELOG.md) for details). The MyGeotab API Adapter binaries are functionally identical between v5.0.0.1 and v5.0.0.3.

**Existing v5.0.0.1 installations of the MyGeotab API Adapter do not need to be upgraded** — there is no functional benefit to doing so. The instructions below apply only if you choose to upgrade for version-alignment purposes.

### 1 Download

Download the application following the [Download](../../README.md#12-download) instructions in the README.

### 2 Stop Application

Stop the MyGeotab API Adapter if it is running.

### 3 Backup Configuration Files

Backup the existing `appsettings.json` and `nlog.config` files (to keep track of the existing setting values).

### 4 Deploy Application

Replace the existing v5.0.0.1 application files with the new v5.0.0.3 application files. Restore the existing `appsettings.json` and `nlog.config` files (backed-up in [Step 3](#3-backup-configuration-files)) by copying them over the new ones — they do not need to be modified.

### 5 Start Application

Start the MyGeotab API Adapter application and monitor it and its logs for several minutes to ensure that it is working properly, indicating that the upgrade was successful.
